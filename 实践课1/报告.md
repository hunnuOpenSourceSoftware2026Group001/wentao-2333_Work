## 任务一 本地安装并启动

在 PowerShell 中执行官方安装命令：

```powershell
powershell -c "irm https://pi.dev/install.ps1 | iex"
```

安装完成后关闭旧终端，重新打开，在一个专用练习文件夹中启动：

```powershell
mkdir pi-test
cd pi-test
pi
```

**截图 S1：** 显示 Pi 已成功启动、版本信息和当前工作目录。只有下载进度不能证明安装完成；出现 `No models available` 表示客户端已启动，下一步需要配置模型。

![S1 Pi 已启动](images/S1-pi-started.png)

## 任务二 配置模型并完成一次会话

任选 API Key 或账户登录一种方式（以 API Key 为例）：

1. 进入模型提供商官方 API 平台（示例：DeepSeek API Platform），在 API keys 页面创建自己的密钥。
2. 回到 Pi，输入 `/login`，选择 `Sign in with an API key`，再搜索并选择提供商。
3. 配置完成后发送：`你好。`

**截图 S2：** 包含自己发出的提示词、模型实际回复和当前模型信息。**不要**提交 `auth.json`、授权回调链接或完整密钥。

![S2 第一次会话](images/S2-first-chat.png)

## 任务三 切换模型与模型思考级别

1. 输入 `/model`（或按 Ctrl+L）打开模型选择器，记录当前模型，再选择另一个可用模型并确认。
2. 切换后发送一个短问题，例如“请用一句话解释持续集成”，确认仍可正常会话。记录切换前后的模型名称。
3. 输入 `/thinking`（或按 Shift+Tab）循环切换当前模型支持的思考级别，记录切换前后状态。

> 思考级别是模型推理设置，不是更换模型；部分模型不支持调整，应换用支持该设置的模型完成练习。

**截图 S3：** 显示模型切换前后名称及思考级别切换前后状态（可用两张截图组合）。

## 任务四 引用代码并粘贴小图片

### A 使用 @ 引用代码文件

在 `pi-test` 文件夹创建 `hello.py`：

```python
def add(a, b):
    return a + b

print(add(2, 3))
```

在该文件夹启动 Pi。输入 `@`，在候选列表中选择 `hello.py`，再发送：

> “请解释 @hello.py 的功能，说明运行后输出什么。只解释，不修改文件。”

检查回复是否解释了 `add` 函数并给出输出 5。

**截图 S4：** 显示引用的文件名、问题和实际回复；若回复区域太长，可用两张截图。

![S4 引用代码文件](images/S4-reference-file.png)

### B 粘贴小图片并测试

准备一张约 200×200 像素的小图片（例如画图画一个蓝色方块，旁边写数字 7），先截取图片内容到剪贴板（不要只复制图片文件的路径）。

切换到明确支持图片输入的模型。在 Pi 输入区按 `Alt+V` 粘贴（macOS 通常 `Ctrl+V`，以 `/hotkeys` 为准），确认出现图片附件提示，再发送：

> “请描述图片中的颜色、形状和数字。”

**截图 S5：** 显示已附加图片的提示、问题和实际回复；报告同时插入原始小图片，便于核对识别结果。

## 任务五 安装并使用一个插件

打开 <https://pi.dev/packages>，自选一个插件，阅读其 npm 或仓库说明，记录名称、来源、安装命令、作用和所需配置。

示例（自选插件可不相同）：

```powershell
pi install npm:pi-web-access
```

安装完成后退出原 Pi 会话，再在终端单独输入 `pi` 重新启动。截图须包含启动后的 `[Extensions]` 区域和插件名称。也可用 `pi list` 辅助核对包来源。

试用一个最小功能，例如 `pi-web-access` 可尝试“请获取 https://example.com 的页面标题”，观察对应工具调用及结果。加载成功与联网功能可用应分别记录。

**截图 S6：** 安装成功输出、重新运行 pi 后的加载信息，以及一次插件功能调用结果。

## 任务六 让 AI 安装一个 PPT Skill（选做项）

在 `D:\projects\study`（或你选择的目录）打开终端并启动 pi，向 AI 发送：

> “请从 https://github.com/anthropics/skills 下载 skills/pptx 完整目录，安装到当前项目的 .pi/skills/pptx。保留 SKILL.md、LICENSE.txt 和 scripts 等支持文件，记录源 commit。只安装这个 Skill，不修改其他项目，不自动安装依赖；如目标已存在先说明情况。完成后列出目录结构。”

检查目录结构：

```text
D:\projects\study\
  .pi\
    skills\
      pptx\
        SKILL.md
        LICENSE.txt
        scripts\
          thumbnail.py
          add_slide.py
          clean.py
          office\ ...
```
